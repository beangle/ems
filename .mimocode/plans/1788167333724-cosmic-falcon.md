# Plan: 在 cache 模块实现 Caffeine 类注册

## 背景

- cache 模块有 `caffeine % "optional"` 依赖，编译期可访问 Caffeine 类
- jcache 模块不在依赖中，无法注册
- EmsAotHints 中有 `registerCaffeineStrategies()` 方法，通过扫描 caffeine jar 注册全部顶层类
- 需要在 cache 模块实现类似逻辑，让 cache 项目自行注册 Caffeine 反射配置

## 改动

### 文件: `/home/chaostone/workspace/beangle/cache/src/main/scala/org/beangle/cache/aot/CacheAotHints.scala`

1. 添加 `registerCaffeineStrategies()` 方法，逻辑与 EmsAotHints 相同：
   - 通过 `classOf[Caffeine[?, ?]].getProtectionDomain.getCodeSource` 获取 jar 路径
   - 遍历 jar 中 `com/github/benmanes/caffeine/cache/` 下的 `.class` 文件
   - 排除 `$` 嵌套类（只注册顶层类）
   - 用 `Class.forName` 加载后按 `caffeinePolicy` 注册

2. `caffeinePolicy` 策略：`DeclaredConstructors + DeclaredFields + DeclaredMethods`

3. 在 `registering()` 中调用 `registerCaffeineStrategies()`
